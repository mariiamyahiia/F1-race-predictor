# F1 Race Predictor

Predicting Formula 1 podium finishes and simulating championship outcomes using 70+ years of historical race data (1950–2026) and a tuned gradient boosting classifier.

## Project Overview

This project uses historical F1 race, qualifying, and standings data to:
1. Predict whether a driver will finish on the podium (top 3) in a given race
2. Validate that prediction across multiple unseen seasons (not just the past it was trained on)
3. Simulate a full season to project a championship winner

## Data Source

Historical F1 data (1950–2026, up to Race 9 of the 2026 season), following the standard Ergast-style relational schema: races, results, qualifying, drivers, constructors, driver/constructor standings, lap times, pit stops, and status/DNF reasons.

Raw CSV files are not included in this repo (see `.gitignore`) — the dataset can be found on Kaggle by searching "Formula 1 Race Data 1950 to 2026."

## Methodology

### Data Cleaning
- Missing values (encoded as `'\N'` in the raw data) properly converted to NaN
- Grid position of `0` (pit lane start) recoded as worse than the last real grid slot
- Verified several apparent "outliers" as legitimate historical F1 quirks rather than data errors: the 2014 double-points finale, the 2019+ fastest-lap bonus point, pre-qualifying era grids exceeding 30 cars (1989), and the Indianapolis 500 as a championship round (1950s)

### Feature Engineering
Six features were built, all using only information available before each race to avoid data leakage:
- **Grid position** — starting position for the race
- **Driver recent form** — rolling average finishing position over the driver's last 3 races
- **Team pace** — constructor's average finishing position over its last 3 races (aggregated to race level first, to avoid double-counting from two drivers per team)
- **Circuit history** — driver's expanding average finish at that specific circuit across all past visits
- **Driver reliability** — DNF rate over the driver's last 5 races
- **Points/standings momentum** — driver's championship points and position going into the race

Two notable bugs were caught and fixed during this stage:
- Team form was initially rolling over individual result rows rather than races, double-counting since each team fields two drivers per race
- Points/standings momentum was initially sorted by `raceId`, which turned out to be a non-chronological database import ID rather than a true time order — early seasons were pulling incorrect "previous race" values as a result. Fixed by sorting on actual `year`/`round`.

### Validation Strategy
Data was split strictly by season, not randomly, to properly simulate predicting races the model has never seen:
- **Train**: 1950–2018
- **Validation**: 2019–2021 (used for tuning)
- **Test**: 2022–2025 (held out, evaluated only once at the end)
- **2026**: reserved separately as an in-progress season for the final championship projection

Missing feature values (drivers/teams with no prior history yet) were filled using medians computed only from the training set, to avoid leaking test-set statistics.

### Model
A gradient boosting classifier (XGBoost) with class weighting to handle the natural imbalance of podium (~15%) vs non-podium results. A small hyperparameter sweep was run across tree depth, learning rate, and number of estimators, selecting the configuration that performed best on a race-specific "top-3 match rate" metric (does the model's top-3 predicted probabilities per race match the actual podium) rather than generic accuracy.

## Results

- **AUC-ROC**: ~0.93–0.94 across validation and the held-out test set
- **Top-3 match rate**: the model correctly identifies ~67–73% of actual podium spots across races
- Benchmarked against a naive baseline (predicting the podium is simply the top-3 qualifiers), the tuned model provides a small but consistent edge — including specifically on "surprise" races where the finishing order didn't match grid order, which is the harder and more meaningful case
- **Feature importance**: grid position dominates (~75%), consistent with real F1 dynamics where overtaking is difficult, but the other features (standings, team form, driver form, reliability, circuit history) collectively contribute meaningful additional signal, particularly on unpredictable races

## Championship Simulation

As a proof of concept, the model was used to simulate the complete 2023 season (a season with a known real outcome) by ranking predicted podium probabilities within each race and applying the official F1 points system. The simulation correctly identified Max Verstappen as champion, and matched the real final standings order for 6 of the top 10 finishers, with the rest off by only a few positions.

The same method was then applied to the in-progress 2026 season (9 of ~24 races complete), using each driver's current form as a proxy for expected performance in the remaining races. This projection is deterministic (it assumes the same predicted finishing order holds for every remaining race), which likely overstates the eventual points margin — a Monte Carlo approach with race-to-race variance is a natural next step for a more realistic, probabilistic projection.

## Limitations & Honest Notes

- Grid position and prior standings dominate the model's predictions; the incremental value of the other features, while real and measurable, is modest
- The model cannot predict race-day incidents (crashes, mechanical failures) that are inherently unforeseeable from pre-race data — this creates a real ceiling on achievable accuracy
- The 2026 projection assumes current form holds steady with no variance across remaining races, which is a simplification
